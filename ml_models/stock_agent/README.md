# Stock Agent Demo

Demo này minh họa tác tử tài chính cho AMZN với bốn công cụ: Forecast Tool, Knowledge Graph, RAG và Report Generator.

Hiện Forecast Tool dùng log-return rolling để chạy nhanh trong web demo. File `train_model.py` là scaffold tạo baseline metrics và `config.json`; có thể thay bằng LSTM/GRU thật khi bổ sung TensorFlow/PyTorch.

Không phải tư vấn đầu tư.
